# Minimum Viable Product (MVP)

PixelPal is an AI-powered personalized desktop companion.
**Product Pitch**: "Turn yourself into a pixel character that lives on your desktop and reacts to your digital life."

## MVP Scope

The MVP encompasses the foundational local-first desktop companion. Its success criterion is:
*A user can upload a photo, see a personalized character on the desktop, and watch it react automatically to at least three real desktop events.*

### Character Features
- Photo upload interface
- AI-generated chibi character integration
- Pixel-art conversion pipeline

### Desktop Features
- Transparent character window
- Draggable character interface
- Always-on-top behavior
- System tray integration

### Monitored Events
- Battery status
- Charging status
- User idle state
- PC lock/unlock

### Reactions
- Idle
- Happy
- Sad
- Worried
- Sleepy
- Surprised

### Interactivity
- Clickable character
- Speech bubble rendering
- Basic personality configuration

---

## Future Scope (Post-MVP)

These features are explicitly excluded from the MVP to maintain focus on the local, deterministic foundation.

- File monitoring
- Download detection
- Application integrations (Spotify, Discord, etc.)
- Network awareness
- Screen-time enhancements
- Notifications parsing
- Voice (TTS/STT)
- Email (Gmail/Outlook)
- Advanced developer integrations (VS Code, GitHub)
- Screen understanding
- Autonomous planning
- Multi-agent behavior
- Marketplace for characters/animations
- Cross-platform support (macOS, Linux)
